 Made It Home – QA Portfolio

 Overview

Made It Home is a mobile safety application designed to help users coordinate events, monitor participant safety, and receive safety-related updates throughout an active event.

I contributed to the Quality Assurance process by testing mobile application features across Android and iOS, validating user flows, identifying defects, and working closely with developers in an Agile environment.

> Note: This repository contains QA documentation and portfolio material only. No proprietary source code, credentials, or confidential client information is included.

 QA Responsibilities

 Performed functional, regression, smoke, exploratory, and usability testing
 Tested Android and iOS builds
 Designed and executed test cases
 Verified application behavior against requirements and expected user flows
 Reported and tracked defects using Jira
 Performed retesting and regression testing after fixes
 Tested background and killed-state application behavior
 Validated push notifications and event-related workflows
 Tested event creation, editing, deletion, invitations, and participant management
 Tested trusted contacts, Safe Circle, monitoring/watcher functionality, and safety workflows
 Tested main events, sub-events, and pit stops
 Tested voice-based event creation and related edge cases
 Collaborated with developers to reproduce and verify reported issues

 Key Learning

Working on Made It Home provided practical experience in testing a real-world mobile application with complex state-based workflows, location-dependent functionality, notifications, background behavior, and multiple user roles.

It strengthened my ability to think beyond happy-path testing and investigate how application behavior changes across different states and user scenarios.
