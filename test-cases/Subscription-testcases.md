# Made It Home – Subscription Test Cases

## Overview

This document contains QA test cases for the **Made It Home subscription and billing module**. The test coverage includes subscription plan visibility, free trials, Pro access, purchases, payment failures, restoration, cancellation, billing issues, renewals, platform-specific subscription management, and subscription status synchronization.

* Billing issues
